# Как установить jQuery-версию

1. Сохрани свою текущую работу в Git. Полный архив распакуй в отдельную папку.
2. Перенеси файлы из папки `chic-flowers` в существующий репозиторий с заменой. Не создавай новый репозиторий и не удаляй свою `.git`.
3. Альтернатива: архив `changes` содержит только новые/изменённые файлы относительно присланного RAR; скопируй его содержимое в корень того же проекта. Он не заменяет фотографии.
4. Открой `index.html` через Live Server. Нужен интернет для CDN jQuery/Bootstrap. Проверь все четыре страницы, корзину между страницами, поля формы и комментарии; открой консоль браузера.
5. `js/old-js-version.js` НЕ подключай: это исходный вариант только для сравнения. Остальные названия скриптов сохранены; второй набор обработчиков добавлять не нужно.
6. Прочитай README, AI_LOG и комментарии REWRITE 1–3. `JQUERY_CHECKLIST.md` помогает найти требования, но не является обязательным репортом.

## Перед отправкой

В исходном RAR уже были отличия HTML/CSS от тега `midterm`. В этой доработке CSS не менялся, а в HTML добавлены только CDN jQuery и комментарий. История и тег не исправлялись задним числом; подробнее — README.

Тесты в данной среде изолированы: реальные загрузку CDN и переходы через Live Server нужно проверить на вашем компьютере. Условия тестов подробно записаны в README и `evidence/jquery-browser-results.json`.

Каждой из вас нужны собственные осмысленные коммиты минимум в три разных дня (не меньше четырёх коммитов), раскрытие AI-помощи и защита. Не приписывай себе несуществующие проверки и не меняй даты коммитов.

Для просмотра изменений: `git status` и `git diff --stat`. В текущем задании не требуется новый тег с определённым именем; старые теги оставь на месте.
